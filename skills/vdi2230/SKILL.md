# VDI 2230 절차 (KB 6.4) — 🟢 Part 1:2015

## Step 0 매번 확인
1 마진 αA(A 1.6~2.0/B 1.4~1.6★/C 1.2~1.4) · 2 μ(표면조합) · 3 FA(방향·크기) · 4 규격+등급

## 계산식 (비자명 연산은 메인세션 Bash 검증)
- FM = αA × Fmin (토크±25%→1.8, ±10%→1.5, 각도±5%→1.3, 유압→1.05~1.1)
- Fmin = FA/(1-Φ) + FKR · Fmax = αA × Fmin
- 응력 σred = √(σM² + 3τM²) ≤ 0.9·Rp0.2(보수) or Rp0.2(표준)
- 토크 MA = FM × [0.5P/π + μG·d2/2 + μK·DKm/2]
- μ기본(🟡): 무처리 0.12~0.18, Anod 0.10~0.16, ChemFilm 0.08~0.14, MoS₂ 0.04~0.10
- 피로 SA = Φ·FAamp/2 ≤ SAzul (Table A9)
- 분리 FKR = Fmin-(1-Φ)FA ≥ 0 · 전단 FQ ≤ μT·FKR·i
